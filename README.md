<img src="assets/astronaut.svg" alt="An astronaut floating among the stars" width="260" align="right">

Hello there! I'm **Abhxym**, an AI/ML engineer who builds systems end to end, from the model or retrieval pipeline to the API and the interface people actually use. Most of my work sits where **LLM agents, search and data engineering** meet, and lately I ship it the cloud-native way with **Docker, Kubernetes and CI/CD**. I like results that explain themselves: every score with its reasons, every README with its limits.

<p align="center">
  🤖 <b>Multi-agent & RAG pipelines</b> with LangGraph, FAISS, Pinecone and rerankers<br>
  🔎 <b>Search & ranking</b>: BM25 + dense retrieval, rank fusion, explainable scoring<br>
  🛰️ <b>Big-data platforms</b> on HDFS, Spark, Kafka and Neo4j<br>
  🧠 <b>Computer vision</b> for medical imaging<br>
  🌐 <b>Full-stack apps</b> deployed and in use<br>
  ☁️ <b>Cloud & DevOps</b>: microservices, Kubernetes, Jenkins, Terraform, Ansible
</p>
